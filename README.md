Battleship Game

A simple two-player Battleship game developed in Python using Tkinter.

Features

Two-player local gameplay.
6x6 game board for each player.
Each player places 5 ships.
Players take turns attacking the opponent's board.
Hit and miss detection.
Previous attacks are saved and displayed.
Automatic player switching after each turn.
Win detection when all opponent's ships are hit.

Technologies

Python 3
Tkinter (GUI library)

Requirements

Python 3.x

Tkinter (included with standard Python installations on Windows).
No additional packages are required.

How to Play

Player 1 places 5 ships on their board.
Player 2 places 5 ships on their board.
Players take turns selecting cells on the opponent's board.
A green cell indicates a hit.
A red cell indicates a miss.
The game automatically switches players after each attack.
The first player to hit all 5 opponent's ships wins.
